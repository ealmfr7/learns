# learns

Laboratorio personal para entender cómo funcionan los programas por debajo de
las abstracciones habituales.

## Rutas de aprendizaje

- [C y sistemas de bajo nivel](c-low-level/ROADMAP.md): C, Linux x86-64,
  memoria, compiladores, ABI, ensamblador e ingeniería inversa.

## Método

El objetivo no es memorizar sintaxis ni producir mucho código. Cada tema sigue
este ciclo:

1. Predecir qué debería suceder.
2. Explicar el modelo mental.
3. Observar el sistema con herramientas reales.
4. Contrastar la predicción con la evidencia.
5. Explicar nuevamente el fundamento con palabras propias.

La dificultad se ajusta mediante preguntas: si una respuesta demuestra dominio,
se avanza; si descubre una laguna, se investiga antes de continuar.
